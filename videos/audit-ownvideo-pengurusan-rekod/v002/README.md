# Audit ownvideo dengan muzik korporat

Versi v002 menaikkan paras muzik instrumental korporat 76 BPM sebanyak 6 dB berbanding v001. Purata muzik berada sekitar 14 dB di bawah narasi Ludo sebelum mastering. Kedua-dua babak, narasi asal dan sari kata dikekalkan. Render 9.667 saat lulus 11 semakan teknikal serta nyahkod penuh.
