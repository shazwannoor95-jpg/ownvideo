# Pemasangan dalam ownvideo

Enam dokumen asal dimuat naik pengguna. Kandungan dikekalkan, nama fail dinormalkan kepada `.md`; ejaan `DEPENDECIES.MD` dibetulkan kepada `DEPENDENCIES.md` bagi pautan Linux. Hash kandungan direkod dalam INSTALL-MANIFEST.json.

Skill dipasang setempat di `~/.agents/skills/google-ai-studio-voiceover/` dan dibundel di `.agents/skills/google-ai-studio-voiceover/` dalam repo. Dalam sesi yang belum menyenaraikannya secara automatik, baca SKILL.md secara terus. Dokumen ini tidak memasang alat CUA, browser baharu atau sesi log masuk Google.

Laporan EVIDENCE_REPORT.md ialah bukti sesi asal, bukan bukti sesi semasa. Akaun, pilihan Ludo, kuota dan hasil WAV perlu disahkan semula dalam UI semasa. Gunakan TLS/proksi hos; jangan pintas polisi rangkaian. Pengguna mengurus log masuk sendiri. Tiada credential dimasukkan ke repo.
